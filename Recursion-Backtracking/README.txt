Coverage check against the assignment PDF:
Question 1: (a) recursive function/base and recursive case; (b) trace/call stack and returned values; (c) time complexity; (d) iterative approach/data structure/comparison; (e) symbolic-link cycle handling.
Question 2: (a) algorithm/state/choices/constraints/goal; (b) decision path and backtracking; (c) trace and state restoration; (d) worst-case time complexity in N, M, L; (e) all-path variant and data structure.
Question 3: (a) brute-force and one-queen-per-row search-space sizes plus discussion of explored states; (b) optimized 1D representation and diagonal arrays; (c) N=4 trace and backtracking; (d) stop after one solution; (e) forbidden squares and complexity impact.

How to compile and run Java files:
- Install a JDK.
- Open a terminal in the folder containing the .java files.
- Compile each file: javac Question1.java
- Run each program: java Question1
Repeat for Question2 and Question3.

Note: The Word files are formatted answer documents. The .java files are separate runnable examples. The Java implementation of Question 1 models the supplied directory structure in memory rather than scanning a real filesystem.
